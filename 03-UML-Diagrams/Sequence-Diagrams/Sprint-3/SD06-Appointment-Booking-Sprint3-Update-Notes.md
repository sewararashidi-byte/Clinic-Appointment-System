# SD06 — Appointment Booking Sequence Diagram: Sprint 3 Update

**Project:** Clinic Appointment System  
**Sprint:** Sprint 3  
**Developer:** Sewara Rashidi  
**Related User Stories:** US-07 — Appointment Booking; US-11 — Appointment Confirmation

## 1. Purpose

The SD06 Appointment Booking Sequence Diagram was originally developed in Sprint 2.

During Sprint 3, the diagram was updated to reflect the implementation of US-11 — Appointment Confirmation.

## 2. Changes Made

- Preserved the existing doctor availability and appointment booking workflow.
- Updated the successful booking flow to redirect patients to the Appointment Confirmation page.
- Added the Confirmation Page and Confirmation Data Loader participants.
- Added secure appointment confirmation retrieval using the appointment ID and authenticated patient ID.
- Added confirmation display and unauthorized-access error scenarios.

## 3. Files

- `SD06-Appointment-Booking-Sprint3.mmd` — Updated Mermaid source code.
- `SD06-Appointment-Booking-Sprint3.svg` — Updated diagram visualization.

## 4. Conclusion

The Sprint 3 version of SD06 extends the original Sprint 2 model to document the implemented appointment confirmation workflow.

The original Sprint 2 diagram and its documentation were preserved for version history.
