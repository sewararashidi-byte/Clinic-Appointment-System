# Clinic Appointment System - Use Case Diagram Plan

## Purpose

This Use Case Diagram provides an overview of the main interactions between users and the Clinic Appointment System.

## Actors

### Patient
- Register
- Login
- Manage Patient Profile
- Search Doctors
- View Doctor Information
- View Doctor Availability
- View Available Appointment Slots
- Book Appointment
- Cancel Appointment
- Reschedule Appointment
- View Appointment Confirmation
- View Appointment History
- Receive Appointment Notifications

### Doctor
- Login
- Manage Doctor Profile
- Manage Availability
- View Scheduled Appointments
- Manage Doctor Schedule

### Receptionist / Administrator
- Login
- Manage Patient Information
- Manage Doctor Information
- Manage Appointments
- Manage Clinic Information

## Sprint 1 Use Cases

The following use cases are implemented during Sprint 1:

- Register
- Login
- Role-Based Access

## Modeling Note

The overall Use Case Diagram represents the complete planned Clinic Appointment System.

The diagram may be refined during later sprints if implementation decisions or requirements change.
